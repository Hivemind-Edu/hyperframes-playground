CRISPR targeting.
Everything depends on
two RNAs and
one permission signal.
The crRNA carries
the address: a
spacer copied from
an old invader.
The tracrRNA is
the handle Cas9
knows how to
grab.
Together, they become
the guide Cas9
can actually use.
Cas9 patrols DNA,
but it does
not read every
base first.
It hunts for
PAM, the short
motif that says:
check here.
No PAM, no
cut.
Even a perfect
match gets ignored.
With PAM present,
Cas9 pries open
a few DNA
bases.
The crRNA tests
the exposed strand
one base at
a time.
A mismatch makes
the complex let
go.
A correct seed
match makes the
target worth testing
fully.
A full match
forms an R-loop
inside the protein.
That R-loop changes
Cas9's shape.
The HNH domain
lines up with
the strand matching
the guide.
The RuvC domain
lines up with
the opposite strand.
Two cuts land
almost together.
The famous edit
begins as a
bacterial memory test.
Dual-RNA targeting is
memory, scaffold, PAM,
match, shape-change, cut.
