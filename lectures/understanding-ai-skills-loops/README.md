# Understanding AI Seminar – Session 3: Lernen mit KI – Skills & Loops

Slide-Deck (Reveal.js) für die 3-stündige Session mit nicht-technischem
Publikum (Mediziner:innen, Psycholog:innen, Wirtschaftswissenschaftler:innen).

## Dateien
- `index.html` – das Deck. Selbst-enthalten, lädt Reveal.js per CDN.
- `skill-hausarbeit.md` – Handout: die „Hausarbeit-Coach“-Skill zum Austeilen.

## Präsentieren
Öffne `index.html` im Browser (Doppelklick oder per lokalem Server).
Für die Speaker-Notes + Timer brauchst du einen lokalen Server:

```bash
bunx serve lectures/understanding-ai-skills-loops
# oder
python3 -m http.server 8000   # dann http://localhost:8000/lectures/understanding-ai-skills-loops/
```

## Steuerung
- `→` / `Leertaste` – weiter, `←` – zurück
- `S` – Speaker-View mit Notizen und Timer
- `O` – Slide-Übersicht, `F` – Vollbild, `Esc` – raus

## Aufbau (≈180 min)
1. Der Wandel im Software Engineering – Verifizierbarkeit, Agenten, Loops, Mindset (35)
2. Lernen verstehen & mit KI analysieren – Reverse Prompting, Learning Sciences, KI-Tutor (40)
3. ☕ Pause (10)
4. Skills – was sie sind & einrichten (25)
5. Praxis – Skill bauen (selbst → auflösen) + Loops (50)
6. Abschluss & Homework Challenge (10)

## Offener Punkt (vor dem Vortrag prüfen)
Slide „Zwei Dinge beim Problemlösen“ verweist auf einen Nobelpreisträger-Aufsatz
zum Lernen (aus dem Briefing). Die exakte Quelle/der Name ist **nicht verifiziert**
(plausibel: Herbert A. Simon). Bitte einsetzen oder den Hinweis entfernen.
Der inhaltliche Punkt (Problemfindung vs. Analyse) ist unabhängig davon belegt.
